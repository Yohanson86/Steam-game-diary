# Steam Library (1800+ игр) & Multi-Platform Game Diary (Android)

Нативное Android-приложение на **Kotlin + Jetpack Compose + Room Database + Coil** с поддержкой облачной сборки `.apk` через **GitHub Actions** и трехуровневым облачным бэкапом (**Яндекс.Диск + Google Диск**).

## Как устроено облачное сохранение и автовосстановление при переустановке
1. **Уровень 1 — Системный автобэкап Android в Google Диск (`backup_rules.xml` & `data_extraction_rules.xml`)**:
   - В `AndroidManifest.xml` прописаны правила автоматического облачного бэкапа базы данных Room (`steam_game_diary.db`) и настроек (`game_diary_prefs.xml`) в ваш Google-аккаунт на смартфоне.
   - При переустановке приложения или переходе на новый Android-смартфон система автоматически восстанавливает базу из Google Диска еще до первого запуска приложения.
2. **Уровень 2 — Прямая синхронизация с Яндекс.Диском в 1 клик (`CloudBackupManager.kt`)**:
   - Использует официальный REST API Яндекс.Диска (`https://cloud-api.yandex.net/v1/disk/resources`).
   - Сохраняет всю базу 1800+ игр Steam (включая ваши оценки, статусы и спарсенные годы релиза) и все записи дневника в файл `disk:/GameDiary/game_diary_backup.json`.
   - Поддерживает тумблер **«Автобэкап на Яндекс.Диск при изменениях»** — при каждом добавлении игры в дневник или смене статуса бэкап в облаке обновляется автоматически.
   - При переустановке достаточно вставить токен и нажать **«📥 Скачать с Яндекс.Диска»**, чтобы вся база вернулась за пару секунд.
3. **Уровень 3 — Универсальный облачный пикер Google Диск / Яндекс.Диск без токенов (Android SAF)**:
   - Кнопки **«📂 Сохранить в Google/Яндекс Диск»** и **«📂 Восстановить из облака»** открывают встроенное системное окно Android (`CreateDocument` / `OpenDocument`), где можно напрямую выбрать папку вашего Google Диска или Яндекс.Диска без настройки API-ключей.
